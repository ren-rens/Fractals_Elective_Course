# Fractals_Elective_Course
Elective course Fractals in FMI - Sofia

## Description of course
Last week of the term there is a pre-exam that consists of questions of everything enlisted on the synopsis.
Last week of the exam term there is an exam.

During the term you have a project to make on a given subject. 
The programming language on which the project could be is on your own preference. 

## To pass
Grade >=3 on the pre-exam/exam

Grade >=3 on the project
